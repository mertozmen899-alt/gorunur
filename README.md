# Norevo

Yerel işletmelerin Google'da ve yapay zekâ cevaplarında (ChatGPT, Gemini) bulunup bulunmadığını ölçen ürünün tanıtım sayfası ve bekleme listesi.

- `index.html`: tanıtım sayfası ve bekleme listesi formu
- `test.html`: 3 soruluk hızlı test
- `aydinlatma.html`: KVKK aydınlatma metni (taslak, köşeli parantezler doldurulmalı)
- Kayıtlar Supabase'deki `bekleme_listesi` tablosuna `katil_bekleme_listesi()` fonksiyonuyla yazılır.

Yayına hazır olunca `<meta name="robots" content="noindex">` satırları kaldırılmalı.
